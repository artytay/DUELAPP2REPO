## Validation Flow

```
┌────────────────────────────────────────────┐
│         VALIDATION CHECKLIST                │
└────────────────────────────────────────────┘

Input: JSON String
   │
   ├─ Step 1: JSON Syntax Check
   │  ├─ Valid JSON?
   │  │  ├─ YES ──▶ Continue
   │  │  └─ NO  ──▶ ❌ "Invalid JSON"
   │  └─ (Check for trailing commas, quotes, etc.)
   │
   ├─ Step 2: Required Fields Check
   │  ├─ Has "title"?
   │  │  ├─ YES ──▶ Continue
   │  │  └─ NO  ──▶ ❌ "Missing title"
   │  └─ Has "items"?
   │     ├─ YES ──▶ Continue
   │     └─ NO  ──▶ ❌ "Missing items"
   │
   ├─ Step 3: Items Array Check
   │  ├─ Is array?
   │  │  ├─ YES ──▶ Continue
   │  │  └─ NO  ──▶ ❌ "Items must be array"
   │  └─ Min 2 items?
   │     ├─ YES ──▶ Continue
   │     └─ NO  ──▶ ❌ "Need at least 2 items"
   │
   ├─ Step 4: Item Structure Check
   │  ├─ Each item an object?
   │  │  ├─ YES ──▶ Continue
   │  │  └─ NO  ──▶ ❌ "Invalid item structure"
   │  └─ Each has "name"?
   │     ├─ YES ──▶ Continue
   │     └─ NO  ──▶ ❌ "Item missing name"
   │
   └─ Step 5: Type Checking
      ├─ Title is string?
      │  ├─ YES ──▶ Continue
      │  └─ NO  ──▶ ❌ "Title must be string"
      └─ Names are strings?
         ├─ YES ──▶ ✅ VALID
         └─ NO  ──▶ ❌ "Names must be strings"

Output: Either VALID ✅ or ERROR ❌ with message
```
